### 👩‍🏫 About

This repository collects projects created by my students while I was their **mentor**
at CODDY. Each student went from their first HTML page to layouts, animations
and small interactive components.

As a mentor, I:
* 🧭 built each student's learning path, from the basics to their own projects
* 🔍 reviewed their code and explained how to improve it
* 🎨 taught not only *how* to write markup, but *why* a layout works: spacing, alignment, hierarchy
